# Cleaning-Up-the-Puzzle-Gallery---Archipelago
Archipelago integration for Cleaning Up the Puzzle Gallery

Required Software

  Steam Version of Cleaning Up the Puzzle Gallery

Installation Procedures

  Acquire the most recent APWorld from the Releases page and place the gallery.apworld in the custom_worlds folder of your Archipelago install

  Download the Mod files and put them into the main game folder. Game folder must include the following:
   - BepInEx (Folder)
   - doorstop_config (File)
   - winhttp.dll (File)

  Download the APworld and place into your custom_worlds folder for Archipelago. Be sure to close out of the client and relaunch it if you installed the APWorld while the Archipelago Application was open. 


Create a Player file (.yaml)

Your player yaml file contains a set of configuration options which provide the generator with information about how it should generate your game. Each player of a multiworld will provide their own file. This setup allows each player to enjoy an experience customized for their taste, and different players in the same multiworld can all have different options.

A copy of the template YAML is in the release tab but it can also be generated by having the Gallery.apworld and generated template options in the Archipelago Client. 
Note: The APWorld name is "Gallery.apworld" and the generated YAML is  "Cleaning Up the Puzzle Gallery.yaml". This may be changed later but is done for simplifying the naming.

Joining a MultiWorld Game
After downloading and extracting the mod folder and files into your base game folder, your main menu should have a UI in the main menu for you to use to connect to your server. Connecting will refresh your main menu page, which can cause stuttering for a few seconds based on your settings. 

Playing the Game
Be sure to load into the correct map that was assigned in your YAML, otherwise checks won't be sent. DO NOT SKIP THE TUTORIALS AS THESE ARE SPHERE 0 CHECKS.
Save Redirection has been set up so that a player SHOULDN'T lose their vanilla or challenge mode saves but this is still partially untested. Backup your main saves before starting just in case.
Saving is disabled for an AP file if you are disconnected while playing. Placing a piece will not count while disconnected either so no puzzles or pieces can be completed while disconnected from the server while on an AP save.
Note: Swapping between servers or disconnecting and reconnecting has been moderately tested but use caution to not swap servers/slots while in a save file as it can corrupt/overwrite the intended file.


YAML Settings

  Game Modes
  - Puzzle Completion - Completing a puzzle sends a check. One location for each puzzle.
  - Piece Placement - Placing a puzzle piece correctly sends a check. One check for each puzzle piece placed correctly.


  Piece Bundles
  - Disabled - Bundles are not enabled. One item per piece.
  - Enabled - Bundles are enabled. Bundles of random pieces are shuffled into bundles and unlocked as checks.
  - Artist - Bundles are enabled but grouped by the Artist who created the puzzle. Bundles of random pieces from the same artist are shuffled into bundles and unlocked as checks.


  Bundle Size
  - Range of 2 - 10 pieces for bundles of pieces. Default is 5.


  Telekinesis Piece Limit
  - An override of the skill Telepathy/Telekinesis that will allow the player to interact with pieces that have not been unlocked if the skill has been unlocked.
  - This was created as a player will need to complete 75/83 Puzzles (on the standard map) or 79/106 Puzzles (on the large map) before they can unlock the skill.
  - This is meant to serve as a Go-Mode/ Goal reach is a player wants to finish without receiving all the pieces in the pool for their slot.
  - The range for this is 1 - 1000 pieces. Default is 10.
  - Note: This will allow a player to complete their seed once it is unlocked, so it is intended to be overpowered.
  - Note: Setting the piece limit to a higher number will cause stuttering and instability. Use caution when setting this limit above 50, and expect heavier stuttering based on your hardware for larger numbers.
  - Note: This will also override the game's intended Telekinesis/Telepathy values (Not tested for Vanilla gameplay, though it should not interfere) so upgrading the skill will not change the effected piece limit.
  

  Map Choice
  - Original Gallery
  - Large Gallery



In Game Settings
I have created a UI for the player to join an AP server that is present in the main menu and while playing in an AP save. 
Two options where created for QoL: Piece Color & Hide Locked.
- Piece Color highlights pieces unlocked so the player can experience the game with all unlocked pieces easily visible while locked pieces maintain the same look.
    - Colors are adjustable based on some choices if you click on the color option, it cycles through options. 
- Hide Locked hides the pieces that are still locked so the player cannot see or interact with them.
- Note: Piece Color highlights differently then Navigational Cortex so using that skill still works as designed.


Win Condition
- Complete all puzzles correctly to finish the game.

Warnings:
- This mod will effect the main menu even on a vanilla game though if you do not connect to an AP server, the UI will go away during a vanilla file.
- This has been tested partially but is an early release. Be sure to backup your main game saves as save redirection has been tested but not heavily stress tested.
- This is an early build, there will be bugs identified. Please report them in the discord channel for Cleaning Up the Puzzle Gallery.
- Auto-saving has not been tested fully so be sure to save every so often to ensure progress is not lost.
